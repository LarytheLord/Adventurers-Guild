# data/

`sample_items.jsonl` (20 items, 10 Hindi + 10 Gujarati) is built by
`scripts/build_sample.py` from the Aya Dataset (CohereLabs/aya_dataset,
Apache-2.0). Each row records dataset, split, pinned revision and row index.
No human labels are stored in this repo; keep them in a private CSV
(`item_id,rater_id,label`).
