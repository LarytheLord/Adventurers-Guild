# Security Policy

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue, pull
request, or discussion for a vulnerability.

You can report in either of these ways:

1. **GitHub private vulnerability reporting** (preferred): go to the
   [Security tab](https://github.com/LarytheLord/Adventurers-Guild/security)
   of this repository and choose "Report a vulnerability".
2. **Email**: abid@guilds.work

Please include:

- what the issue is and where it is (URL, route, or file)
- steps to reproduce, or a proof of concept
- the impact as you understand it
- your name or handle if you would like to be credited

## What to expect

- We acknowledge your report within 5 working days.
- We will tell you whether we can reproduce it and what we plan to do.
- We ask that you keep the details private until a fix is released.

## Scope

This policy covers the code in this repository and the production site at
https://guilds.work.

Please do not access, change, or delete data that is not yours, and do not run
denial-of-service or automated high-volume tests against the production site.
If you find user data while testing, stop and report it instead of collecting it.

## Supported versions

Only the current `main` branch and the version deployed at guilds.work are
supported. Fixes are not backported.
